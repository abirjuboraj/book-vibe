# Book Vibe

A simple book discovery website where you can explore popular books, check their details, and build your own reading list.

**Live Demo:** [https://book-vibe-topaz.vercel.app/](https://book-vibe-topaz.vercel.app/)

![Book Vibe Screenshot](./public/screenshot.png)

---

## Overview

Book Vibe helps readers find their next favorite book. You can browse books by category, see each book's rating, author, and tags, and open a details page to learn more. It also has pages to keep track of the books you've listed and the pages you plan to read.

---

## Main Technologies

- **Next.js** for the framework and routing
- **React** for building the UI
- **Tailwind CSS** for styling
- **Recharts** for the reading charts
- **React Icons** for icons
- **React Toastify** for notifications
- **Vercel** for hosting

---

## Features

- **Book collection** with cover, category, rating, author, and tags
- **Book details page** for each book
- **Category filter** for Fiction, Romance, Classic, and Mystery
- **Read List** and **Wishlist** to save the books you've read or want to read
- **Sorting** for both lists by rating, number of pages, or published year
- **Pages to Read** page with a chart to track your reading
- **Toast notifications** when you add a book to the Read List or Wishlist
- **Sign In / Sign Up** pages (design only, not functional yet)
- **Responsive design** that works on mobile, tablet, and desktop

## How to Run Locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/abirjuboraj/book-vibe.git
   ```

2. **Go to the project folder**
   ```bash
   cd book-vibe
   ```

3. **Install dependencies**
   ```bash
   npm install
   ```

4. **Start the development server**
   ```bash
   npm run dev
   ```

5. **Open in browser**
   Go to [http://localhost:3000](http://localhost:3000)
